**Astree** — двусторонний CLI-инструмент для надёжного преобразования текстовых представлений деревьев каталогов в реальные файловые структуры и обратного анализа проектов.

Спроектирован как мост между инженером, большими языковыми моделями (LLM) и локальной файловой системой:
1. **Tree &rarr; Repo (Scaffold):** превращает схемы каталогов из чата, документации или Markdown-блоков в рабочий проект с правильными шебангами, правами исполнения и шаблонами.
2. **Repo &rarr; Tree (Dump):** извлекает компактную схему репозитория с описаниями файлов из docstring и заголовков, соблюдая `.gitignore` и фильтруя бинарный шум.

Доступен в виде **нативного бинарника на Rust** (`astree`) и **Python-пакета** (`astree-py`) с измеримым и протестированным функциональным паритетом.

## ⚡ Быстрый старт

### 1. Развернуть проект из схемы дерева
```bash
astree << 'EOF'
my_service/
├── pyproject.toml              # автоматически получит шаблон PEP 621
├── README.md                   # Core service documentation
├── .gitignore                  # базовые исключения для Python/Rust
├── scripts/
│   └── migrate.py*             # получит shebang #!/usr/bin/env python3 и chmod +x
└── src/
    ├── __init__.py             # = __version__ = "0.2.2"
    └── server.py               # service entrypoint
EOF
```

### 2. Снять дамп существующего проекта для промпта LLM
```bash
astree dump . -L 2 -h
```
Вывод:
```text
my_service/
├── [ 280B]  pyproject.toml
├── [ 412B]  README.md # Core service documentation
├── [  30B]  scripts/
│   └── [ 641B]  migrate.py* # migration script
└── [  30B]  src/
    ├── [  22B]  __init__.py
    └── [ 1.2K]  server.py # service entrypoint
```

## 🔒 Модель безопасности и остаточная модель угроз

Astree спроектирован с защитой от типовых атак при обработке недоверенных схем каталогов:
- **Защита от Path Traversal (CWE-22):** абсолютные пути (`/etc/...`), относительные переходы (`..`), а также промежуточные и корневые символические ссылки, разрешающиеся за пределы целевого каталога, блокируются с ошибкой `PermissionDenied`.
- **Защита от Symlink Hijacking (CWE-59):** при разворачивании файлов поверх существующих симлинков операция без `--force` завершается отказом. При использовании `--force` симлинк предварительно удаляется (`unlink`), гарантируя, что запись никогда не будет выполнена в файл-мишень по ссылке.
- **Атомарная запись на уровне файлов:** без `--force` файлы создаются атомарно флагом ядра `O_CREAT | O_EXCL` (в Python режим `"x"`, в Rust `create_new(true)`). С `--force` запись ведётся в уникальный временный файл с последующим `rename`/`os.replace`.
- **Остаточная модель угроз:** полная изоляция от гонок TOCTOU на родительских каталогах при наличии локального процесса, конкурентно подменяющего промежуточные папки дерева, гарантируется только операционными системами с поддержкой дескрипторного разрешения путей (Linux 5.6+ `openat2` с `RESOLVE_BENEATH`). Для переносимости между Unix-системами Astree проводит предварительный рекурсивный аудит компонентов пути, однако в многопользовательских окружениях с общим доступом к каталогу рекомендуется запускать утилиту в изолированном пространстве имён или контейнере.

## 📖 Справочник командной строки

### Разворачивание структуры (Scaffold)
```text
astree [FILE] [OPTIONS]
```
* `FILE`: путь к файлу с деревом или `-` для чтения из stdin.
* `-t, --target-dir <DIR>`: целевой каталог для разворачивания (по умолчанию `.`).
* `-c, --clip`: прочитать дерево напрямую из системного буфера обмена (`wl-paste`, `xclip`, `pbpaste`).
* `-d, --dry-run`: превью планируемых действий без модификации диска.
* `-f, --force`: перезапись существующих файлов и разрыв существующих симлинков.
* `--no-shebang`: отключить автогенерацию shebang-строк.
* `--no-templates`: не генерировать стандартный бойлерплейт для `pyproject.toml`, `README.md`, `.gitignore`.

#### Синтаксис Tree DSL:
* `file.sh*` — звёздочка на конце добавляет права исполнения (`chmod 755`) и shebang.
* `file.py # = code` — знак `=` записывает строку выражения непосредственно в файл.
* `link -> target` — создаёт символическую ссылку.
* `[notes] file.txt` — скобки в именах файлов сохраняются, если они не являются префиксом размера `tree -h`.

---

### Анализ структуры репозитория (Dump)
```text
astree dump [DIR] [OPTIONS]
```
* `DIR`: каталог для анализа (по умолчанию `.`).
* `-L, --level <N>`: максимальная глубина обхода (целое число `>= 0`).
* `-I, --ignore <REGEX>`: регулярное выражение для фильтрации файлов и папок.
* `-h, --human-readable`: выводить размер файлов в формате `tree -h` (`[   0B]`, `[ 1.5K]`, `[  12K]`).
* `-d, --dirs-only`: выводить только каталоги.
* `-o, --output <FILE>`: сохранить вывод в файл.
